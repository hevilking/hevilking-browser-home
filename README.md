# hevilking的浏览器主页

一款简洁、轻巧且高度可定制的浏览器起始页扩展插件。

## 主要
- **自定义动态背景**：支持本地图库（Local）及丰富的在线壁纸源（Online）。
- **极简高效**：基于原生 HTML/CSS/JS 开发，加载速度快。

## 安装
### 本地
1. 将本项目克隆或下载解压到本地。
2. 打开浏览器的扩展管理页面。
3. 开启右上角的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择本项目的根目录即可体验。

### 在线
在插件扩展市场搜索即可[hevilking的浏览器主页](https://microsoftedge.microsoft.com/addons/Microsoft-Edge-Extensions-Home)
