# hevilking的浏览器主页

一款简洁、轻巧且高度可定制的浏览器起始页扩展插件。

## 主要功能
- **自定义背景**：支持本地图库及丰富的在线壁纸源（Bing 每日、Picsum），可调模糊/亮度/饱和度等滤镜
- **多引擎搜索**：支持 Google、Bing、百度、DuckDuckGo，含搜索联想与历史记录
- **快捷方式管理**：支持添加/编辑/删除/拖拽排序/导入导出，支持搜索过滤，含 URL 重复检测
- **极简高效**：基于原生 HTML/CSS/JS 开发，加载速度快

## 安装
### 本地
1. 将本项目克隆或下载解压到本地
2. 打开浏览器的扩展管理页面
3. 开启 **开发者模式**
4. 点击 **加载已解压的扩展程序**，选择本项目的根目录即可体验

### 在线
点击[hevilking的浏览器主页](https://microsoftedge.microsoft.com/addons/detail/hdhnemiamgpfghgnlkmkolojlhekmimd)跳转安装即可
