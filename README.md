# hevilking的浏览器主页

**简体中文** | [English](README.en.md)

一款简洁、轻巧且高度可定制的浏览器起始页扩展插件。

## 主要功能

- **自定义背景**：支持本地图库及丰富的在线壁纸源（Bing 每日、Picsum），可调模糊/亮度/饱和度等滤镜
- **多引擎搜索**：支持 Google、Bing、百度、DuckDuckGo，含搜索联想与历史记录
- **快捷方式管理**：支持添加/编辑/删除/拖拽排序/导入导出，支持搜索过滤，含 URL 重复检测
- **中英文界面**：默认简体中文，可在设置中切换 English，覆盖表单、提示及无障碍标签
- **极简高效**：基于原生 HTML/CSS/JS 开发，加载速度快

## 界面语言

- 点击齿轮打开“设置”，在顶部“通用 → 界面语言”中选择“简体中文”或“English”。首次使用固定为简体中文，之后沿用已保存的选择。
- 选择后整页文案即时预览，无需刷新；点击“保存”记住语言，取消或关闭恢复原语言。“恢复默认”也会将语言预览为中文。
- 切换语言保留搜索内容、光标、快捷方式名称、图片文件名和未保存的设置。语言与背景一同提交，写入失败时可重试或取消。
- 文案集中于 `js/i18n/zh-CN.js` 和 `js/i18n/en.js`，支持带参数及单复数的提示，缺失翻译回退中文。

## 背景与外观

- 点击齿轮打开分组侧栏，按背景来源、自动轮播、外观效果和本地图库调整；高级滤镜默认折叠。
- 调整会实时预览，点击“保存”才记住配置；取消或关闭恢复原参数和壁纸，有未保存改动时点击页面空白不会关闭。
- 预览期间暂停自动轮播，调节滤镜保持同一张图片；图片模式才显示轮播和图片滤镜。
- 滑块与数值框同步，轮播支持常用间隔和自定义秒数；纯色支持十六进制颜色，渐变提供六组预设。
- “恢复默认”先预览默认配置，保存后才生效。
- 图片库上传、删除独立即时保存，不随取消设置撤销；图片仅保存在本机，单张最多 8MB、合计 80MB、最多 30 张。

## 搜索引擎切换

- 点击搜索框左侧的当前引擎展开下拉菜单，点击选项立即切换；点击外部或再次点击入口收起。
- 自动记住所选引擎，保留已输入的搜索词和光标选区，选择后回到输入框继续搜索。
- 下拉菜单与搜索历史、联想列表互斥；切换后按新引擎刷新联想词。

## 快捷方式排序

- 添加和编辑使用统一的深色表单，支持取消和点击遮罩关闭；打开时直接聚焦名称，关闭后返回原操作位置。
- 右上角排序图标提供鼠标操作说明，悬停或点击即可查看气泡，再次点击或点击外部关闭。
- 按住鼠标左键拖动卡片，松手放置，占位框实时显示落点；支持跨行、末尾空白和边缘自动滚动。
- 触屏长按约 250 毫秒后拖动；长按前滑动仍可滚动列表。长按放下后可操作该卡片的编辑、删除按钮。
- 鼠标在列表外松手会取消排序；拖动时标题旁显示临时状态。完成后页面底部出现 5 秒“撤销”浮层，不占用卡片布局，悬停或聚焦撤销入口时暂停计时。
- 搜索有关键词时暂停排序，帮助气泡会说明原因；点击搜索框内的 × 可清除搜索，搜索中的编辑、删除仍作用于对应网站。

## 安装

### 本地

1. 将本项目克隆或下载解压到本地
2. 打开浏览器的扩展管理页面
3. 开启 **开发者模式**
4. 点击 **加载已解压的扩展程序**，选择本项目的根目录即可体验

### 在线

点击[hevilking的浏览器主页](https://microsoftedge.microsoft.com/addons/detail/hdhnemiamgpfghgnlkmkolojlhekmimd)跳转安装即可
