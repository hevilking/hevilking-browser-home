# 浏览器主页扩展

这是一个美观的浏览器主页扩展，可以将你的新标签页替换为自定义的主页界面。

## 功能特性

- 🎨 美观的界面设计
- 🔍 多搜索引擎支持（Google、百度、Bing、DuckDuckGo）
- ⚡ 快捷方式管理
- 🖼️ 壁纸切换功能
- 📚 搜索历史记录
- 📱 响应式设计

## 安装方法

### 在Microsoft Edge中安装

1. 打开Microsoft Edge浏览器
2. 在地址栏输入 `edge://extensions/` 并回车
3. 开启"开发人员模式"（右上角的开关）
4. 点击"加载解压缩的扩展"
5. 选择项目文件夹 
6. 扩展将自动安装并启用

### 在Google Chrome中安装

1. 打开Google Chrome浏览器
2. 在地址栏输入 `chrome://extensions/` 并回车
3. 开启"开发者模式"（右上角的开关）
4. 点击"加载已解压的扩展程序"
5. 选择项目文件夹 
6. 扩展将自动安装并启用

## 使用方法

1. 安装扩展后，打开新的标签页即可看到自定义主页
2. 在搜索框中输入内容进行搜索
3. 点击搜索引擎按钮切换不同的搜索引擎
4. 使用快捷方式快速访问常用网站
5. 点击壁纸切换按钮更换背景

## 配置说明

### manifest.json 主要配置

- `manifest_version`: 3 (使用最新的Manifest V3)
- `chrome_url_overrides`: 将新标签页替换为自定义主页
- `permissions`: 存储权限，用于保存用户设置
- `icons`: 扩展图标配置

## 注意事项

- 确保浏览器支持Manifest V3
- 扩展需要"新标签页"权限才能正常工作
- 首次安装后可能需要重启浏览器

## 故障排除

如果扩展无法正常工作：

1. 检查浏览器是否支持Manifest V3
2. 确认扩展已正确安装并启用
3. 尝试重新加载扩展
4. 检查浏览器控制台是否有错误信息
